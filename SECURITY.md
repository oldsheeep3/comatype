# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it privately with GitHub's
[private vulnerability reporting](https://github.com/oldsheeep3/comatype/security/advisories/new)
(Security tab → Report a vulnerability). You can expect a first reply within a few days.

## Supported versions

Comatype is pre-1.0. Only the latest release receives fixes.
