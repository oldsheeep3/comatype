# Changelog

## 0.0.2

First release on the VS Code Marketplace and Open VSX.

- Language server client for `comatype lsp`: diagnostics, go to definition, hover, completion and outline.
- TextMate grammar, snippets (including every status code) and language configuration for `.comat`.
- JSON schema for `comatype.config.json`.
- Commands: generate, check, restart the language server, export and import OpenAPI, show status codes.
