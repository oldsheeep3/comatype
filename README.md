# Comatype

English | [日本語](README.ja.md)

Write your API once in `.comat` files. Comatype generates types, validation, clients and servers for eight languages from them.

```comat
// comatfiles/user/[id]/put.comat  →  PUT /user/:id
import UserData from ../../../types/UserData.comat

params {
    id: uuidv4,
}

body UserData

s200 UserData
s404 ApiError
```

The language, the CLI and the generated code are specified in [SPEC.md](SPEC.md). A runnable sample project is in [usage/](usage/).

## Languages

TypeScript, Go, Python, Rust, Java, Kotlin, Swift and Ruby — each as a client and as a server. A client generated by Comatype is tested end to end against a server generated by Comatype, in every language.

## The command line

```bash
# install a prebuilt binary (macOS, Linux; on Windows use the zip on the release page)
curl -fsSL https://raw.githubusercontent.com/oldsheeep3/comatype/main/install.sh | sh
# or build it from source:  cargo install --git https://github.com/oldsheeep3/comatype comatype-cli

comatype check                    # check every .comat file
comatype generate                 # generate code for the targets in comatype.config.json
comatype endpoints -g             # list endpoints, grouped by wrapper chain
comatype format comatfiles --fix  # rewrite file names to the recommended layout
comatype to-openapi -o openapi.yml
```

The configuration file is `comatype.config.json`; its JSON Schema is [schema/comatype.config.schema.json](schema/comatype.config.schema.json) (the VS Code extension applies it automatically).

## Repository layout

| Path | Contents |
|---|---|
| `crates/` | Parser, checker, generators, OpenAPI conversion, language server and the CLI (Rust) |
| `packages/` | Runtimes that generated code depends on (`c` client, `s` server) |
| `editors/vscode/` | VS Code extension: highlighting, diagnostics, go to definition, completion |
| `docs/` | The website (Next.js static export; English at `/`, Japanese at `/ja-jp/`) |
| `usage/` | Sample project with generated code for every language |
| `scripts/` | Generated-code checks and end-to-end scripts |

## Development

```bash
cargo test
pnpm install
pnpm --dir docs dev               # http://localhost:5173
pnpm --dir docs check             # typecheck, build, test

./scripts/e2e-client.sh           # TypeScript
./scripts/e2e-go.sh
./scripts/e2e-python.sh           # needs a root .venv
./scripts/e2e-rust.sh
./scripts/e2e-java.sh             # needs JDK 21+
./scripts/e2e-kotlin.sh           # needs a JDK and kotlinc
./scripts/e2e-swift.sh            # needs Swift 5.9+
./scripts/e2e-ruby.sh             # needs Ruby 3.1+
```

Branches: `main` is the release, `develop` is the next version, `hotfix` is for urgent patches. Releasing is described in [RELEASING.md](RELEASING.md).
