# Comatype for Swift

Comatype runtime for Swift (Swift Package `Comatype`): an async client on URLSession and an async server on POSIX sockets. Foundation only.

[Source](https://github.com/oldsheeep3/comatype/tree/main/packages/swift) · [Documentation](https://comatype.sheeplab.net) · [GitHub](https://github.com/oldsheeep3/comatype)

> Comatype: write an API once in `.comat` files, get types, validation, a client and a server in eight languages.
> This package is the **Swift** runtime that the generated code depends on.

## How to use

### Install

SwiftPM needs `Package.swift` at the repository root, so for now the runtime is used as a local package (a registry release is planned):

```bash
git clone https://github.com/oldsheeep3/comatype
```

```swift
// Package.swift
dependencies: [.package(path: "../comatype/packages/swift")],
targets: [
    .target(name: "ComatypeGen", dependencies: [.product(name: "Comatype", package: "swift")]),
]
```

macOS 12 / iOS 15 or later, Swift 5.9 or later. Put the generated code in the target `ComatypeGen` (the default output is `Sources/ComatypeGen`).

The `comatype` command (parser, checker and generators) is separate from the runtime:

```bash
curl -fsSL https://raw.githubusercontent.com/oldsheeep3/comatype/main/install.sh | sh
```

This downloads the prebuilt `comatype` command (and its short alias `comat`) for macOS (arm64, x64) and Linux (x64, arm64) from the [latest release](https://github.com/oldsheeep3/comatype/releases/latest); no Rust toolchain needed. On Windows, download `comatype-x86_64-pc-windows-msvc.zip` from the release page. To build it from source instead: `cargo install --git https://github.com/oldsheeep3/comatype comatype-cli`.

### Import

```swift
import Comatype        // C (client), S (server), CookieJar, CookieValue, ...
import ComatypeGen     // generated: Types, ComatypeInit, one enum per .comat file (UserPutId, ...)
import Foundation
```

### Format / Lint

Generated files start with `// Code generated by comatype generate. DO NOT EDIT.` Keep them out of `swift-format` and SwiftLint:

```yaml
# .swiftlint.yml
excluded:
  - Sources/ComatypeGen
```

```bash
swift format lint --strict -r Sources/YourApp   # pass your own source directories, not Sources/ComatypeGen
```

### Check

```bash
comatype check                  # check every .comat file; prints [error] / [warn] / [info] lines, exits 1 on errors
comatype check cache            # only one topic: cache, path, wrap, cookie, status, import, type
comatype endpoints -g           # list the endpoints, grouped by wrapper chain
comatype generate --lang swift # generate the code (swift only)
```

Run `comatype check` in CI so that a broken `.comat` never reaches the generated code.

### init.comat

`init.comat` holds the settings of the whole project. Put exactly one directly under `comatDir`.

```comat
// comatfiles/init.comat
import UserData from ../types/UserData.comat
import ApiError from ../types/common.comat

// The base url of every endpoint. Override it at run time with the COMATYPE_BASE_URL environment variable
baseUrl https://api.example.com

// The cookie the server issues (for `cookie on` endpoints)
cookie session {
    httpOnly: true,
    secure: true,
    sameSite: lax,
}

// A wrapper: what it adds to `ctx`, and the statuses it can return. You implement it in Swift
wrapper auth {
    ctx {
        user: UserData,
    }
    s401 ApiError
}
```

### comatfiles

A `.comat` file is one endpoint. Its method and path come from where the file is and what it is called.

```text
comatfiles/
├─ init.comat               baseUrl, cookie, wrapper declarations (exactly one)
├─ defaults.comat           defaults for this directory and below: wrap, headers, shared statuses
├─ post_user.comat          POST /user
└─ user/
   ├─ [id]/put.comat        PUT /user/:id        ([id] is a dynamic segment)
   ├─ (noauth)/             a group: not part of the path
   │  ├─ defaults.comat     wrap auth off
   │  ├─ post_login.comat   POST /user/login
   │  └─ get_ping.comat     GET /user/ping
   └─ get.comat             GET /user
types/                      types shared by endpoints (outside comatDir)
```

`comatype.config.json` says where `comatfiles` is and what to generate:

```json
{
  "$schema": "https://raw.githubusercontent.com/oldsheeep3/comatype/main/schema/comatype.config.schema.json",
  "services": {
    "api": {
      "comatDir": "./comatfiles",
      "targets": [{ "lang": "swift", "role": "client", "root": "./" }]
    }
  }
}
```

See the [syntax reference](https://comatype.sheeplab.net/language/endpoint/) for `params`, `search`, `body`, headers, status codes and `path`.

## Example

### ComatFiles

```comat
// types/UserData.comat
UserData {
    name: string,
    email: email,
    phone: phone,
    uid: uuidv4,
}
```

```comat
// comatfiles/user/[id]/put.comat  ->  PUT /user/:id
import UserData from ../../../types/UserData.comat
import ApiError from ../../../types/common.comat

params {
    id: uuidv4,
}

body UserData

s200 UserData
s404 ApiError
```

```comat
// comatfiles/defaults.comat: applies to every endpoint below
import ApiError from ../types/common.comat

wrap auth        // the wrapper declared in init.comat
cookie on        // send and receive the session cookie
s500 ApiError    // every endpoint can answer 500
```

```comat
// comatfiles/user/(noauth)/defaults.comat: this group needs no login
wrap auth off
```

```comat
// comatfiles/user/(noauth)/post_login.comat  ->  POST /user/login
import ApiError from ../../../types/common.comat

body {
    email: email,
    password: string,
}

s200 {
    uid: uuidv4,
}
// the auth wrapper is off in this group, so declare the 401 yourself
s401 ApiError
```

Generate the Swift code with `comatype generate --lang swift`.

### Client

```swift
import Comatype
import ComatypeGen
import Foundation

func putUser(id: UUID, user: UserData) async throws {
    let res = try await C.put(UserPutId.endpoint, UserPutId.Request(params: .init(id: id), body: user))

    switch res {
    case .s200(let data, _): _ = data     // UserData (the second value is S200Headers)
    case .s404(let error, _): _ = error   // ApiError
    default: break
    }
}
```

Calls are `async throws` on URLSession. A status that is not in the `.comat` throws `ComatypeError.unexpectedStatus`; invalid input throws `ValidationError` before any network call.

### Server

```swift
import Comatype
import ComatypeGen

let s = S()

s.put(UserPutId.endpoint) { req in
    guard let user = db.user.update(req.params.id, req.body) else {
        return S.Reply(.s404(body: ApiError(code: "not_found", message: "user not found")))
    }
    return S.Reply(.s200(body: user, headers: UserPutId.S200Headers(xResourceVersion: "v2")))
}

_ = try s.serve(host: "127.0.0.1", port: 3000)
```

`s.serve` is an HTTP/1.1 server on POSIX sockets without TLS (terminate TLS in a proxy). `await s.handle(method:target:headers:body:)` fits any framework.

### Wrapper & Cookie

A wrapper wraps the request and the response: authentication, headers, logging. Declare it in `init.comat`, enable it with `wrap auth` in a `defaults.comat` or in an endpoint, and implement it in Swift.

```swift
// client: add a header to every request
let auth: C.ComatypeWrap = { req, next in
    var r = req
    r.headers.set("Authorization", "Bearer \(token)")
    return try await next(r)
}
C.initialize(C.Config(wrappers: ComatypeInit.Wrappers(auth: auth), cookieJar: CookieJar()))
```

```swift
// server: authenticate and add ctx.user (typed from `ctx { user: UserData }` in init.comat)
let auth: S.ComatypeWrap<ComatypeInit.AuthCtx> = { req, next in
    guard let user = verifySession(req.cookie("session")) else {
        return ComatypeInit.s401(ApiError(code: "unauthorized", message: "login required"))
    }
    return try await next(req.withCtx(ComatypeInit.AuthCtx(user: user)))
}
s.initialize(wrappers: ComatypeInit.Wrappers(auth: auth))
```

```swift
// server: issue the session cookie (declared in init.comat; the endpoint has `cookie on`)
return S.Reply(.s200(body: UserPostLogin.S200Res(uid: uid))).withCookie(CookieValue(token, maxAge: 3600))
```

A wrapper missing from `ComatypeInit.Wrappers` is a compile error.

### Cache

Caching is declared in the `.comat` file, once, for the client and the server (GET and QUERY endpoints only):

```comat
// comatfiles/user/(noauth)/get_ping.comat  ->  GET /user/ping
s200 {
    ok: bool,
}

cache 60000          // cache the response in memory for 60 seconds
```

| Declaration | Meaning |
|---|---|
| (none) | no caching |
| `cache off` | never cache |
| `cache 5000` | in memory for 5000 ms (client and server) |
| `cache 5000 cookie` | in a cookie for 5000 ms (client only) |

- The server looks the cache up before the wrappers, with the exact request (method, path, query, all headers, body) as the key.
- The client looks it up just before the network call, with the method, URL, body and the request headers declared in the `.comat`.
- Only 2xx responses without `Set-Cookie` are cached. `cache` in `defaults.comat` or `init.comat` is ignored with a warning.
```swift
C.clearCache()   // drop the client cache, for example on logout
```
