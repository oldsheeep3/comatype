# comatype for Go

Comatype runtime for Go: the client `c`, the server `s` and the shared types in `comatype`.

[pkg.go.dev](https://pkg.go.dev/github.com/oldsheeep3/comatype/packages/go) · [Documentation](https://comatype.sheeplab.net) · [GitHub](https://github.com/oldsheeep3/comatype)

> Comatype: write an API once in `.comat` files, get types, validation, a client and a server in eight languages.
> This package is the **Go** runtime that the generated code depends on.

## How to use

### Install

```bash
go get github.com/oldsheeep3/comatype/packages/go@latest
```

Go 1.22 or later. The module lives in a subdirectory, so its tags are `packages/go/vX.Y.Z`. Set `importPath` on the target in `comatype.config.json` (or let it follow your `go.mod`).

The `comatype` command (parser, checker and generators) is separate from the runtime:

```bash
curl -fsSL https://raw.githubusercontent.com/oldsheeep3/comatype/main/install.sh | sh
```

This downloads the prebuilt `comatype` command (and its short alias `comat`) for macOS (arm64, x64) and Linux (x64, arm64) from the [latest release](https://github.com/oldsheeep3/comatype/releases/latest); no Rust toolchain needed. On Windows, download `comatype-x86_64-pc-windows-msvc.zip` from the release page. To build it from source instead: `cargo install --git https://github.com/oldsheeep3/comatype comatype-cli`.

### Import

```go
import (
    "github.com/oldsheeep3/comatype/packages/go/c"         // client
    "github.com/oldsheeep3/comatype/packages/go/s"         // server
    "github.com/oldsheeep3/comatype/packages/go/comatype"  // shared types: Uuidv4, Email, MaxAge, ...

    user_put_id "example.com/app/comatype/user/put__id"    // generated: one package per .comat file
    comatype_init "example.com/app/comatype/init"          // generated: wrappers, ctx, wrapper statuses
)
```

### Format / Lint

The generator runs `gofmt` on its output when `gofmt` is installed, and every file starts with `// Code generated by comatype generate. DO NOT EDIT.` so `go vet`, `golangci-lint` and `gopls` treat it as generated code.

```yaml
# .golangci.yml
issues:
  exclude-dirs: [comatype]
```

Run `go vet ./...` and `go test ./...` as usual.

### Check

```bash
comatype check                  # check every .comat file; prints [error] / [warn] / [info] lines, exits 1 on errors
comatype check cache            # only one topic: cache, path, wrap, cookie, status, import, type
comatype endpoints -g           # list the endpoints, grouped by wrapper chain
comatype generate --lang go # generate the code (go only)
```

Run `comatype check` in CI so that a broken `.comat` never reaches the generated code.

### init.comat

`init.comat` holds the settings of the whole project. Put exactly one directly under `comatDir`.

```comat
// comatfiles/init.comat
import UserData from ../types/UserData.comat
import ApiError from ../types/common.comat

// The base url of every endpoint. Override it at run time with the COMATYPE_BASE_URL environment variable
baseUrl https://api.example.com

// The cookie the server issues (for `cookie on` endpoints)
cookie session {
    httpOnly: true,
    secure: true,
    sameSite: lax,
}

// A wrapper: what it adds to `ctx`, and the statuses it can return. You implement it in Go
wrapper auth {
    ctx {
        user: UserData,
    }
    s401 ApiError
}
```

### comatfiles

A `.comat` file is one endpoint. Its method and path come from where the file is and what it is called.

```text
comatfiles/
├─ init.comat               baseUrl, cookie, wrapper declarations (exactly one)
├─ defaults.comat           defaults for this directory and below: wrap, headers, shared statuses
├─ post_user.comat          POST /user
└─ user/
   ├─ [id]/put.comat        PUT /user/:id        ([id] is a dynamic segment)
   ├─ (noauth)/             a group: not part of the path
   │  ├─ defaults.comat     wrap auth off
   │  ├─ post_login.comat   POST /user/login
   │  └─ get_ping.comat     GET /user/ping
   └─ get.comat             GET /user
types/                      types shared by endpoints (outside comatDir)
```

`comatype.config.json` says where `comatfiles` is and what to generate:

```json
{
  "$schema": "https://raw.githubusercontent.com/oldsheeep3/comatype/main/schema/comatype.config.schema.json",
  "services": {
    "api": {
      "comatDir": "./comatfiles",
      "targets": [{ "lang": "go", "role": "client", "root": "./server" }]
    }
  }
}
```

See the [syntax reference](https://comatype.sheeplab.net/language/endpoint/) for `params`, `search`, `body`, headers, status codes and `path`.

## Example

### ComatFiles

```comat
// types/UserData.comat
UserData {
    name: string,
    email: email,
    phone: phone,
    uid: uuidv4,
}
```

```comat
// comatfiles/user/[id]/put.comat  ->  PUT /user/:id
import UserData from ../../../types/UserData.comat
import ApiError from ../../../types/common.comat

params {
    id: uuidv4,
}

body UserData

s200 UserData
s404 ApiError
```

```comat
// comatfiles/defaults.comat: applies to every endpoint below
import ApiError from ../types/common.comat

wrap auth        // the wrapper declared in init.comat
cookie on        // send and receive the session cookie
s500 ApiError    // every endpoint can answer 500
```

```comat
// comatfiles/user/(noauth)/defaults.comat: this group needs no login
wrap auth off
```

```comat
// comatfiles/user/(noauth)/post_login.comat  ->  POST /user/login
import ApiError from ../../../types/common.comat

body {
    email: email,
    password: string,
}

s200 {
    uid: uuidv4,
}
// the auth wrapper is off in this group, so declare the 401 yourself
s401 ApiError
```

Generate the Go code with `comatype generate --lang go`.

### Client

```go
import (
    "context"

    "github.com/oldsheeep3/comatype/packages/go/c"
    "github.com/oldsheeep3/comatype/packages/go/comatype"
    user_put_id "example.com/app/comatype/user/put__id"
)

func PutUser(ctx context.Context, id string, user user_put_id.Body) error {
    res, err := c.Put(ctx, user_put_id.Endpoint, user_put_id.Request{
        Params: user_put_id.Params{ID: comatype.Uuidv4(id)},
        Body:   user,
    })
    if err != nil {
        return err // a validation error (*comatype.ValidationError) comes back before any network call
    }

    switch res.Status {
    case 200:
        _ = res.S200 // *user_put_id.S200Res
    case 404:
        _ = res.S404 // *user_put_id.S404Res
    }
    return nil
}
```

A status that is not in the `.comat` is a `*comatype.UnexpectedStatusError`. Optional (`?`) fields are pointers; `c.Ptr(true)` makes one.

### Server

```go
import (
    "net/http"

    "github.com/oldsheeep3/comatype/packages/go/s"
    user_put_id "example.com/app/comatype/user/put__id"
)

func main() {
    s.Put(user_put_id.Endpoint, func(req user_put_id.Request) user_put_id.Response {
        user, ok := db.Update(req.Params.ID, req.Body)
        if !ok {
            return user_put_id.S404(&user_put_id.S404Res{Code: "not_found", Message: "user not found"})
        }
        return user_put_id.S200(&user_put_id.S200Res{Name: user.Name, Email: user.Email, Phone: user.Phone, UID: user.UID})
    })

    http.ListenAndServe(":3000", s.Handler())
}
```

### Wrapper & Cookie

A wrapper wraps the request and the response: authentication, headers, logging. Declare it in `init.comat`, enable it with `wrap auth` in a `defaults.comat` or in an endpoint, and implement it in Go.

```go
// client: add a header to every request
var Auth c.ComatypeWrap = func(req *c.RawRequest, next c.Next) (*c.RawResponse, error) {
    req.Header.Set("Authorization", "Bearer "+token)
    return next(req)
}

c.Init(c.Config{
    Wrappers:  comatype_init.Wrappers{Auth: Auth},
    CookieJar: c.NewCookieJar(), // keeps Set-Cookie of `cookie on` endpoints
})
```

```go
// server: authenticate and add ctx.User (typed from `ctx { user: UserData }` in init.comat)
var Auth s.ComatypeWrap[comatype_init.AuthCtx] = func(req *s.RawRequest[comatype_init.AuthCtx], next s.Next[comatype_init.AuthCtx]) s.RawResponse {
    user, ok := verifySession(req.Cookie("session"))
    if !ok {
        return comatype_init.S401(&comatype_init.S401Res{Code: "unauthorized", Message: "login required"})
    }
    req.Ctx = comatype_init.AuthCtx{User: user}
    return next(req)
}

s.Init(s.Config{Wrappers: comatype_init.Wrappers{Auth: Auth}})
```

```go
// server: issue the session cookie (declared in init.comat; the endpoint has `cookie on`)
return user_post_login.S200(&user_post_login.S200Res{UID: user.UID}).WithCookie(token, comatype.MaxAge(3600))
// delete it with .ClearCookie()
```

Go cannot check at compile time that every wrapper is passed; a missing one is an error when an endpoint that uses it is called.

### Cache

Caching is declared in the `.comat` file, once, for the client and the server (GET and QUERY endpoints only):

```comat
// comatfiles/user/(noauth)/get_ping.comat  ->  GET /user/ping
s200 {
    ok: bool,
}

cache 60000          // cache the response in memory for 60 seconds
```

| Declaration | Meaning |
|---|---|
| (none) | no caching |
| `cache off` | never cache |
| `cache 5000` | in memory for 5000 ms (client and server) |
| `cache 5000 cookie` | in a cookie for 5000 ms (client only) |

- The server looks the cache up before the wrappers, with the exact request (method, path, query, all headers, body) as the key.
- The client looks it up just before the network call, with the method, URL, body and the request headers declared in the `.comat`.
- Only 2xx responses without `Set-Cookie` are cached. `cache` in `defaults.comat` or `init.comat` is ignored with a warning.
```go
c.ClearCache() // drop the client cache, for example on logout
```
