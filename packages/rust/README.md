# comatype for Rust

Comatype runtime for Rust: a blocking client `comatype::c` (ureq) and a small server `comatype::s`, with serde types.

[crates.io](https://crates.io/crates/comatype) · [docs.rs](https://docs.rs/comatype) · [Documentation](https://comatype.sheeplab.net) · [GitHub](https://github.com/oldsheeep3/comatype)

> Comatype: write an API once in `.comat` files, get types, validation, a client and a server in ten languages.
> This package is the **Rust** runtime that the generated code depends on.

## How to use

### Install

```bash
cargo add comatype
```

Depends on `serde`, `serde_json`, `regex` and `ureq`. Generated code goes to `<root>/src/comatype_gen/` by default; add `mod comatype_gen;` to `main.rs` (or `lib.rs`).

The `comatype` command (parser, checker and generators) is separate from the runtime:

```bash
curl -fsSL https://raw.githubusercontent.com/oldsheeep3/comatype/main/install.sh | sh
```

This downloads the prebuilt `comatype` command (and its short alias `comat`) for macOS (arm64, x64) and Linux (x64, arm64) from the [latest release](https://github.com/oldsheeep3/comatype/releases/latest); no Rust toolchain needed. On Windows, download `comatype-x86_64-pc-windows-msvc.zip` from the release page. To build it from source instead: `cargo install --git https://github.com/oldsheeep3/comatype comatype-cli`.

### Import

```rust
mod comatype_gen;                                   // the generated module

use comatype::c;                                    // client: c::get / c::put / c::init ...
use comatype::s::{ComatypeWrap, Reply, Server};     // server
use comatype::{CookieJar, CookieValue};

use comatype_gen::init::{self as cinit, AuthCtx, Wrappers};
use comatype_gen::types::{ApiError, UserData};
use comatype_gen::user_put_id::{self, Request, Response};   // one module per .comat file
```

### Format / Lint

The generator runs `rustfmt` on its output when it is installed (so your `rustfmt.toml` applies), and each generated file starts with `// Code generated by comatype generate. DO NOT EDIT.` followed by `#![allow(...)]` for the usual lints. If you still want to skip it:

```rust
// src/main.rs
#[rustfmt::skip]
mod comatype_gen;
```

Use `cargo clippy` as usual.

### Check

```bash
comatype check                  # check every .comat file; prints [error] / [warn] / [info] lines, exits 1 on errors
comatype check cache            # only one topic: cache, path, wrap, cookie, status, import, type
comatype endpoints -g           # list the endpoints, grouped by wrapper chain
comatype generate --lang rust # generate the code (rust only)
```

Run `comatype check` in CI so that a broken `.comat` never reaches the generated code.

### init.comat

`init.comat` holds the settings of the whole project. Put exactly one directly under `comatDir`.

```comat
// comatfiles/init.comat
import UserData from ../types/UserData.comat
import ApiError from ../types/common.comat

// The base url of every endpoint. Override it at run time with the COMATYPE_BASE_URL environment variable
baseUrl https://api.example.com

// The cookie the server issues (for `cookie on` endpoints)
cookie session {
    httpOnly: true,
    secure: true,
    sameSite: lax,
}

// A wrapper: what it adds to `ctx`, and the statuses it can return. You implement it in Rust
wrapper auth {
    ctx {
        user: UserData,
    }
    s401 ApiError
}
```

### comatfiles

A `.comat` file is one endpoint. Its method and path come from where the file is and what it is called.

```text
comatfiles/
├─ init.comat               baseUrl, cookie, wrapper declarations (exactly one)
├─ defaults.comat           defaults for this directory and below: wrap, headers, shared statuses
├─ post_user.comat          POST /user
└─ user/
   ├─ [id]/put.comat        PUT /user/:id        ([id] is a dynamic segment)
   ├─ (noauth)/             a group: not part of the path
   │  ├─ defaults.comat     wrap auth off
   │  ├─ post_login.comat   POST /user/login
   │  └─ get_ping.comat     GET /user/ping
   └─ get.comat             GET /user
types/                      types shared by endpoints (outside comatDir)
```

`comatype.config.json` says where `comatfiles` is and what to generate:

```json
{
  "$schema": "https://raw.githubusercontent.com/oldsheeep3/comatype/main/schema/comatype.config.schema.json",
  "services": {
    "api": {
      "comatDir": "./comatfiles",
      "targets": [{ "lang": "rust", "role": "client", "root": "./server" }]
    }
  }
}
```

See the [syntax reference](https://comatype.sheeplab.net/language/endpoint/) for `params`, `search`, `body`, headers, status codes and `path`.

## Example

### ComatFiles

```comat
// types/UserData.comat
UserData {
    name: string,
    email: email,
    phone: phone,
    uid: uuidv4,
}
```

```comat
// comatfiles/user/[id]/put.comat  ->  PUT /user/:id
import UserData from ../../../types/UserData.comat
import ApiError from ../../../types/common.comat

params {
    id: uuidv4,
}

body UserData

s200 UserData
s404 ApiError
```

```comat
// comatfiles/defaults.comat: applies to every endpoint below
import ApiError from ../types/common.comat

wrap auth        // the wrapper declared in init.comat
cookie on        // send and receive the session cookie
s500 ApiError    // every endpoint can answer 500
```

```comat
// comatfiles/user/(noauth)/defaults.comat: this group needs no login
wrap auth off
```

```comat
// comatfiles/user/(noauth)/post_login.comat  ->  POST /user/login
import ApiError from ../../../types/common.comat

body {
    email: email,
    password: string,
}

s200 {
    uid: uuidv4,
}
// the auth wrapper is off in this group, so declare the 401 yourself
s401 ApiError
```

Generate the Rust code with `comatype generate --lang rust`.

### Client

```rust
use comatype::c;
use comatype_gen::types::UserData;
use comatype_gen::user_put_id::{self, Request, Response};

fn put_user(id: &str, user: UserData) -> comatype::Result<()> {
    let res = c::put(
        &user_put_id::ENDPOINT,
        Request { params: user_put_id::Params { id: id.into() }, body: user, ..Default::default() },
    )?;

    match res {
        Response::S200(data, _headers) => drop(data), // UserData; _headers is S200Headers
        Response::S404(error, _) => drop(error),      // ApiError
        _ => {}
    }
    Ok(())
}
```

The client is **blocking**. A status that is not in the `.comat` is `Error::UnexpectedStatus`; invalid input is `Error::Validation` before any network call.

### Server

```rust
use comatype::s::Server;
use comatype_gen::types::ApiError;
use comatype_gen::user_put_id::{self, Reply, Response, S200Headers};
use std::sync::Arc;

fn main() {
    let server = Arc::new(Server::new());

    server.put(&user_put_id::ENDPOINT, move |req| -> Reply {
        let Some(user) = db.update(&req.params.id.0, req.body) else {
            return Response::S404(ApiError { code: "not_found".into(), message: "user not found".into() }, Default::default()).into();
        };
        let headers = S200Headers { x_resource_version: Some("v2".into()), ..Default::default() };
        Response::S200(user, headers).into()
    });

    server.serve("127.0.0.1:3000", |addr| println!("listening on {addr}")).unwrap();
}
```

`server.serve` is a plain standard-library server (a thread per connection). `server.handle(method, target, headers, body)` is the entry point for any framework.

### Wrapper & Cookie

A wrapper wraps the request and the response: authentication, headers, logging. Declare it in `init.comat`, enable it with `wrap auth` in a `defaults.comat` or in an endpoint, and implement it in Rust.

```rust
// client: add a header to every request
use comatype::c::{self, ComatypeWrap, Config};
use std::sync::Arc;

let auth = ComatypeWrap::new(|mut req, next| {
    req.headers.set("Authorization", format!("Bearer {token}"));
    next(req)
});
c::init(Config { cookie_jar: Some(Arc::new(CookieJar::new())), ..Config::default().wrappers(Wrappers { auth }) });
```

```rust
// server: authenticate and add ctx.user (typed from `ctx { user: UserData }` in init.comat)
let auth = ComatypeWrap::<AuthCtx>::new(|req, next| {
    let Some(user) = verify_session(req.cookie("session")) else {
        return cinit::s401(ApiError { code: "unauthorized".into(), message: "login required".into() });
    };
    next(req.with_ctx(AuthCtx { user }))
});
server.init(Wrappers { auth });
```

```rust
// server: issue the session cookie (declared in init.comat; the endpoint has `cookie on`)
Reply::from(Response::S200(res, Default::default())).with_cookie(CookieValue::new(token).max_age(3600))
// delete it with .clear_cookie()
```

A wrapper missing from `Wrappers { .. }` is a compile error.

### Cache

Caching is declared in the `.comat` file, once, for the client and the server (GET and QUERY endpoints only):

```comat
// comatfiles/user/(noauth)/get_ping.comat  ->  GET /user/ping
s200 {
    ok: bool,
}

cache 60000          // cache the response in memory for 60 seconds
```

| Declaration | Meaning |
|---|---|
| (none) | no caching |
| `cache off` | never cache |
| `cache 5000` | in memory for 5000 ms (client and server) |
| `cache 5000 cookie` | in a cookie for 5000 ms (client only) |

- The server looks the cache up before the wrappers, with the exact request (method, path, query, all headers, body) as the key.
- The client looks it up just before the network call, with the method, URL, body and the request headers declared in the `.comat`.
- Only 2xx responses without `Set-Cookie` are cached. `cache` in `defaults.comat` or `init.comat` is ignored with a warning.
```rust
c::clear_cache(); // drop the client cache, for example on logout
```
