# comatype for Ruby

Comatype runtime for Ruby: the client `Comatype::C` (Net::HTTP) and a Rack-compatible server `Comatype::S`. Standard library only.

[RubyGems](https://rubygems.org/gems/comatype) · [Documentation](https://comatype.sheeplab.net) · [GitHub](https://github.com/oldsheeep3/comatype)

> Comatype: write an API once in `.comat` files, get types, validation, a client and a server in nine languages.
> This package is the **Ruby** runtime that the generated code depends on.

## How to use

### Install

```bash
gem install comatype        # or add `gem "comatype"` to your Gemfile
```

Ruby 3.1 or later, no other dependency. Generated code goes to `<root>/comatype_gen/` by default.

The `comatype` command (parser, checker and generators) is separate from the runtime:

```bash
curl -fsSL https://raw.githubusercontent.com/oldsheeep3/comatype/main/install.sh | sh
```

This downloads the prebuilt `comatype` command (and its short alias `comat`) for macOS (arm64, x64) and Linux (x64, arm64) from the [latest release](https://github.com/oldsheeep3/comatype/releases/latest); no Rust toolchain needed. On Windows, download `comatype-x86_64-pc-windows-msvc.zip` from the release page. To build it from source instead: `cargo install --git https://github.com/oldsheeep3/comatype comatype-cli`.

### Import

```ruby
require "comatype"                        # Comatype::C (client), Comatype::S (server)
require_relative "comatype_gen/all"       # generated: requires every generated file

UserPutId = ComatypeGen::UserPutId        # one class per .comat file (PascalCase)
# ComatypeGen::Types  named types
# ComatypeGen::Init   wrappers, ctx, wrapper statuses
```

### Format / Lint

Every generated file starts with `# frozen_string_literal: true` and `# Code generated by comatype generate. DO NOT EDIT.` Exclude the directory from RuboCop:

```yaml
# .rubocop.yml
AllCops:
  Exclude:
    - comatype_gen/**/*
```

### Check

```bash
comatype check                  # check every .comat file; prints [error] / [warn] / [info] lines, exits 1 on errors
comatype check cache            # only one topic: cache, path, wrap, cookie, status, import, type
comatype endpoints -g           # list the endpoints, grouped by wrapper chain
comatype generate --lang ruby # generate the code (ruby only)
```

Run `comatype check` in CI so that a broken `.comat` never reaches the generated code.

### init.comat

`init.comat` holds the settings of the whole project. Put exactly one directly under `comatDir`.

```comat
// comatfiles/init.comat
import UserData from ../types/UserData.comat
import ApiError from ../types/common.comat

// The base url of every endpoint. Override it at run time with the COMATYPE_BASE_URL environment variable
baseUrl https://api.example.com

// The cookie the server issues (for `cookie on` endpoints)
cookie session {
    httpOnly: true,
    secure: true,
    sameSite: lax,
}

// A wrapper: what it adds to `ctx`, and the statuses it can return. You implement it in Ruby
wrapper auth {
    ctx {
        user: UserData,
    }
    s401 ApiError
}
```

### comatfiles

A `.comat` file is one endpoint. Its method and path come from where the file is and what it is called.

```text
comatfiles/
├─ init.comat               baseUrl, cookie, wrapper declarations (exactly one)
├─ defaults.comat           defaults for this directory and below: wrap, headers, shared statuses
├─ post_user.comat          POST /user
└─ user/
   ├─ [id]/put.comat        PUT /user/:id        ([id] is a dynamic segment)
   ├─ (noauth)/             a group: not part of the path
   │  ├─ defaults.comat     wrap auth off
   │  ├─ post_login.comat   POST /user/login
   │  └─ get_ping.comat     GET /user/ping
   └─ get.comat             GET /user
types/                      types shared by endpoints (outside comatDir)
```

`comatype.config.json` says where `comatfiles` is and what to generate:

```json
{
  "$schema": "https://raw.githubusercontent.com/oldsheeep3/comatype/main/schema/comatype.config.schema.json",
  "services": {
    "api": {
      "comatDir": "./comatfiles",
      "targets": [{ "lang": "ruby", "role": "client", "root": "./server" }]
    }
  }
}
```

See the [syntax reference](https://comatype.sheeplab.net/language/endpoint/) for `params`, `search`, `body`, headers, status codes and `path`.

## Example

### ComatFiles

```comat
// types/UserData.comat
UserData {
    name: string,
    email: email,
    phone: phone,
    uid: uuidv4,
}
```

```comat
// comatfiles/user/[id]/put.comat  ->  PUT /user/:id
import UserData from ../../../types/UserData.comat
import ApiError from ../../../types/common.comat

params {
    id: uuidv4,
}

body UserData

s200 UserData
s404 ApiError
```

```comat
// comatfiles/defaults.comat: applies to every endpoint below
import ApiError from ../types/common.comat

wrap auth        // the wrapper declared in init.comat
cookie on        // send and receive the session cookie
s500 ApiError    // every endpoint can answer 500
```

```comat
// comatfiles/user/(noauth)/defaults.comat: this group needs no login
wrap auth off
```

```comat
// comatfiles/user/(noauth)/post_login.comat  ->  POST /user/login
import ApiError from ../../../types/common.comat

body {
    email: email,
    password: string,
}

s200 {
    uid: uuidv4,
}
// the auth wrapper is off in this group, so declare the 401 yourself
s401 ApiError
```

Generate the Ruby code with `comatype generate --lang ruby`.

### Client

```ruby
require "comatype"
require_relative "comatype_gen/all"

UserPutId = ComatypeGen::UserPutId

def put_user(id, user)
  res = Comatype::C.put(UserPutId::ENDPOINT, params: { id: id }, body: user)

  case res
  when UserPutId::S200 then res.body   # UserData (res.headers is S200Headers)
  when UserPutId::S404 then res.body   # ApiError
  end
end
```

A status that is not in the `.comat` raises `Comatype::UnexpectedStatusError`; invalid input raises `Comatype::ValidationError` before any network call. Ruby is dynamic, so the generated code describes the types and the runtime validates them.

### Server

```ruby
require "comatype"
require_relative "comatype_gen/all"

UserPutId = ComatypeGen::UserPutId

server = Comatype::S.new

server.put(UserPutId::ENDPOINT) do |req|
  user = Db::User.update(req.params.id, req.body)
  next UserPutId::S404.new(ComatypeGen::Types::ApiError.new(code: "not_found", message: "user not found")) unless user

  UserPutId::S200.new(user, headers: { x_resource_version: "v2" })
end

# config.ru: `run server` (Rack compatible), or a plain standard-library server:
server.serve(port: 3000)
```

### Wrapper & Cookie

A wrapper wraps the request and the response: authentication, headers, logging. Declare it in `init.comat`, enable it with `wrap auth` in a `defaults.comat` or in an endpoint, and implement it in Ruby.

```ruby
# client: add a header to every request
AUTH = lambda do |req, nxt|
  req.headers["Authorization"] = "Bearer #{token}"
  nxt.call(req)
end

Comatype::C.init(wrappers: ComatypeGen::Init.wrappers(auth: AUTH), cookies: true)   # cookies: true keeps a jar
```

```ruby
# server: authenticate and add ctx[:auth].user (typed from `ctx { user: UserData }` in init.comat)
AUTH = lambda do |req, nxt|
  user = verify_session(req.cookie("session"))
  next ComatypeGen::Init.s401(ComatypeGen::Types::ApiError.new(code: "unauthorized", message: "login required")) unless user

  req.ctx[:auth] = ComatypeGen::Init::AuthCtx.new(user: user)
  nxt.call(req)
end

server.init(ComatypeGen::Init.wrappers(auth: AUTH))
```

```ruby
# server: issue the session cookie (declared in init.comat; the endpoint has `cookie on`)
UserPostLogin::S200.new(UserPostLogin::S200Res.new(uid: uid)).with_cookie(token, max_age: 3600)
# delete it with .clear_cookie
```

### Cache

Caching is declared in the `.comat` file, once, for the client and the server (GET and QUERY endpoints only):

```comat
// comatfiles/user/(noauth)/get_ping.comat  ->  GET /user/ping
s200 {
    ok: bool,
}

cache 60000          // cache the response in memory for 60 seconds
```

| Declaration | Meaning |
|---|---|
| (none) | no caching |
| `cache off` | never cache |
| `cache 5000` | in memory for 5000 ms (client and server) |
| `cache 5000 cookie` | in a cookie for 5000 ms (client only) |

- The server looks the cache up before the wrappers, with the exact request (method, path, query, all headers, body) as the key.
- The client looks it up just before the network call, with the method, URL, body and the request headers declared in the `.comat`.
- Only 2xx responses without `Set-Cookie` are cached. `cache` in `defaults.comat` or `init.comat` is ignored with a warning.
```ruby
Comatype::C.clear_cache   # drop the client cache, for example on logout
```
