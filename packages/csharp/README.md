# Comatype for C#

Comatype runtime for C# (.NET 8+): records, sealed response hierarchies, an async client on `HttpClient` and a server on `HttpListener`. No external dependencies.

[NuGet](https://www.nuget.org/packages/Comatype) · [Documentation](https://comatype.sheeplab.net) · [GitHub](https://github.com/oldsheeep3/comatype)

> Comatype: write an API once in `.comat` files, get types, validation, a client and a server in ten languages.
> This package is the **C#** runtime that the generated code depends on.

## How to use

### Install

```bash
dotnet add package Comatype
```

.NET 8 or later (records, pattern matching, nullable reference types). Generated code goes to `<root>/ComatypeGen/` by default, in the namespace `ComatypeGen` (set `package` on the target to change the namespace).

The `comatype` command (parser, checker and generators) is separate from the runtime:

```bash
curl -fsSL https://raw.githubusercontent.com/oldsheeep3/comatype/main/install.sh | sh
```

This downloads the prebuilt `comatype` command (and its short alias `comat`) for macOS (arm64, x64) and Linux (x64, arm64) from the [latest release](https://github.com/oldsheeep3/comatype/releases/latest); no Rust toolchain needed. On Windows, download `comatype-x86_64-pc-windows-msvc.zip` from the release page. To build it from source instead: `cargo install --git https://github.com/oldsheeep3/comatype comatype-cli`.

### Import

```csharp
using Comatype;       // C (client), S (server), CookieJar, CookieValue, ValidationException, ...
using ComatypeGen;    // generated: Types (named types), Init (wrappers, ctx), one static class per .comat file (PascalCase)
```

### Format / Lint

Generated files start with `// <auto-generated>` and `// Code generated by comatype generate. DO NOT EDIT.`, so the compiler, `dotnet format` and most analyzers already skip them. To be explicit:

```ini
# .editorconfig
[ComatypeGen/**.cs]
generated_code = true
```

### Check

```bash
comatype check                  # check every .comat file; prints [error] / [warn] / [info] lines, exits 1 on errors
comatype check cache            # only one topic: cache, path, wrap, cookie, status, import, type
comatype endpoints -g           # list the endpoints, grouped by wrapper chain
comatype generate --lang csharp # generate the code (csharp only)
```

Run `comatype check` in CI so that a broken `.comat` never reaches the generated code.

### init.comat

`init.comat` holds the settings of the whole project. Put exactly one directly under `comatDir`.

```comat
// comatfiles/init.comat
import UserData from ../types/UserData.comat
import ApiError from ../types/common.comat

// The base url of every endpoint. Override it at run time with the COMATYPE_BASE_URL environment variable
baseUrl https://api.example.com

// The cookie the server issues (for `cookie on` endpoints)
cookie session {
    httpOnly: true,
    secure: true,
    sameSite: lax,
}

// A wrapper: what it adds to `ctx`, and the statuses it can return. You implement it in C#
wrapper auth {
    ctx {
        user: UserData,
    }
    s401 ApiError
}
```

### comatfiles

A `.comat` file is one endpoint. Its method and path come from where the file is and what it is called.

```text
comatfiles/
├─ init.comat               baseUrl, cookie, wrapper declarations (exactly one)
├─ defaults.comat           defaults for this directory and below: wrap, headers, shared statuses
├─ post_user.comat          POST /user
└─ user/
   ├─ [id]/put.comat        PUT /user/:id        ([id] is a dynamic segment)
   ├─ (noauth)/             a group: not part of the path
   │  ├─ defaults.comat     wrap auth off
   │  ├─ post_login.comat   POST /user/login
   │  └─ get_ping.comat     GET /user/ping
   └─ get.comat             GET /user
types/                      types shared by endpoints (outside comatDir)
```

`comatype.config.json` says where `comatfiles` is and what to generate:

```json
{
  "$schema": "https://raw.githubusercontent.com/oldsheeep3/comatype/main/schema/comatype.config.schema.json",
  "services": {
    "api": {
      "comatDir": "./comatfiles",
      "targets": [{ "lang": "csharp", "role": "client", "root": "./Server" }]
    }
  }
}
```

See the [syntax reference](https://comatype.sheeplab.net/language/endpoint/) for `params`, `search`, `body`, headers, status codes and `path`.

## Example

### ComatFiles

```comat
// types/UserData.comat
UserData {
    name: string,
    email: email,
    phone: phone,
    uid: uuidv4,
}
```

```comat
// comatfiles/user/[id]/put.comat  ->  PUT /user/:id
import UserData from ../../../types/UserData.comat
import ApiError from ../../../types/common.comat

params {
    id: uuidv4,
}

body UserData

s200 UserData
s404 ApiError
```

```comat
// comatfiles/defaults.comat: applies to every endpoint below
import ApiError from ../types/common.comat

wrap auth        // the wrapper declared in init.comat
cookie on        // send and receive the session cookie
s500 ApiError    // every endpoint can answer 500
```

```comat
// comatfiles/user/(noauth)/defaults.comat: this group needs no login
wrap auth off
```

```comat
// comatfiles/user/(noauth)/post_login.comat  ->  POST /user/login
import ApiError from ../../../types/common.comat

body {
    email: email,
    password: string,
}

s200 {
    uid: uuidv4,
}
// the auth wrapper is off in this group, so declare the 401 yourself
s401 ApiError
```

Generate the C# code with `comatype generate --lang csharp`.

### Client

```csharp
using Comatype;
using ComatypeGen;

static async Task PutUser(Guid id, Types.UserData user)
{
    UserPutId.Response res = await C.PutAsync(UserPutId.Endpoint,
        new UserPutId.Request(new UserPutId.Params(id), UserPutId.RequestHeaders.Empty(), user));

    switch (res)
    {
        case UserPutId.S200 ok:
            Types.UserData data = ok.Body;      // ok.Headers is S200Headers
            break;
        case UserPutId.S404 notFound:
            Types.ApiError error = notFound.Body;
            break;
    }
}
```

`Response` is an abstract record with one sealed record per status, so `switch` with pattern matching works. A status that is not in the `.comat` throws `ComatypeException.UnexpectedStatus`; invalid input throws `ValidationException` before any network call. Optional fields are `T?`; copy a record with `with`, for example `UserGet.Search.Empty() with { Limit = 10 }`.

### Server

```csharp
using Comatype;
using ComatypeGen;

var s = new S();

s.Put(UserPutId.Endpoint, req =>
{
    Types.UserData? user = db.Update(req.Params.Id, req.Body);
    if (user == null)
        return new UserPutId.S404(new Types.ApiError("not_found", "user not found"), UserPutId.S404Headers.Empty());
    return new UserPutId.S200(user, UserPutId.S200Headers.Empty() with { XResourceVersion = "v2" });
});

using var server = s.Serve("127.0.0.1", 3000);   // System.Net.HttpListener; s.HandleAsync(method, target, headers, body) fits any framework
await Task.Delay(Timeout.Infinite);
```

A handler can also be `async` (`async req => ...`).

### Wrapper & Cookie

A wrapper wraps the request and the response: authentication, headers, logging. Declare it in `init.comat`, enable it with `wrap auth` in a `defaults.comat` or in an endpoint, and implement it in C#.

```csharp
// client: add a header to every request
C.ComatypeWrap auth = (req, next) =>
{
    req.Headers.Set("Authorization", "Bearer " + token);
    return next(req);
};
C.Init(new C.Config().WithWrappers(new Init.Wrappers(auth)).WithCookieJar(new CookieJar()));
```

```csharp
// server: authenticate and add ctx.User (typed from `ctx { user: UserData }` in init.comat)
S.ComatypeWrap<Init.AuthCtx> auth = (req, next) =>
{
    Types.UserData? user = VerifySession(req.Cookie("session"));
    if (user == null) return Task.FromResult(Init.S401(new Types.ApiError("unauthorized", "login required")));
    return next(req.WithCtx(new Init.AuthCtx(user)));
};
s.Init(new Init.Wrappers(auth));
```

```csharp
// server: issue the session cookie (declared in init.comat; the endpoint has `cookie on`)
return S.Reply<UserPostLogin.Response>
    .Of(new UserPostLogin.S200(new UserPostLogin.S200Res(uid), UserPostLogin.S200Headers.Empty()))
    .WithCookie(CookieValue.Of(token).WithMaxAge(3600));
```

A wrapper missing from `Init.Wrappers` is a compile error.

### Cache

Caching is declared in the `.comat` file, once, for the client and the server (GET and QUERY endpoints only):

```comat
// comatfiles/user/(noauth)/get_ping.comat  ->  GET /user/ping
s200 {
    ok: bool,
}

cache 60000          // cache the response in memory for 60 seconds
```

| Declaration | Meaning |
|---|---|
| (none) | no caching |
| `cache off` | never cache |
| `cache 5000` | in memory for 5000 ms (client and server) |
| `cache 5000 cookie` | in a cookie for 5000 ms (client only) |

- The server looks the cache up before the wrappers, with the exact request (method, path, query, all headers, body) as the key.
- The client looks it up just before the network call, with the method, URL, body and the request headers declared in the `.comat`.
- Only 2xx responses without `Set-Cookie` are cached. `cache` in `defaults.comat` or `init.comat` is ignored with a warning.
```csharp
C.ClearCache();   // drop the client cache, for example on logout
```
