# @comatype/typescript

Runtime for TypeScript code generated by [Comatype](https://github.com/oldsheeep3/comatype): the client `c` and the server `s`.

```ts
import { c } from '@comatype/typescript'
import { s } from '@comatype/typescript'
import { serve } from '@comatype/typescript/node'
```

See the [documentation](https://github.com/oldsheeep3/comatype#readme).
